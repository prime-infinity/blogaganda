# Blogaganda

Full-stack Qloo API explorer with Express backend and React frontend.

## Setup

1. Install dependencies:
```bash
npm run install-all
```

2. Configure backend:
```bash
cd backend
cp .env.example .env
# Edit .env and add your QLOO_API_KEY
```

3. Start both servers:
```bash
npm start
```

Backend runs on http://localhost:3001
Frontend runs on http://localhost:5173
